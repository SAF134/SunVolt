# SunVolt - Energi Masa Depan untuk Perjalanan Bersih

SunVolt adalah aplikasi Flutter premium untuk memantau status pengisian daya kendaraan listrik, mengelola dompet digital (top-up), dan memantau riwayat transaksi pengisian daya dengan antarmuka "Solar Kinetic" yang bersih dan modern.

## Fitur Utama
- **Monitoring Real-time**: Pantau tegangan (V) dan arus (A) saat pengisian daya.
- **Top-up Mudah**: Pilihan nominal pengisian daya yang fleksibel (termasuk opsi Percobaan Rp 1).
- **Riwayat Transaksi**: Lacak penggunaan energi Anda secara mendetail.
- **Keamanan Berlapis**: Konfirmasi bertahap untuk tindakan krusial seperti berhenti mengisi daya.
- **Desain Premium**: Antarmuka berbasis tonal layering dan tanpa garis untuk pengalaman pengguna yang maksimal.

## Cara Menjalankan
1. Pastikan Flutter SDK telah terinstal di sistem Anda.
2. Clone repository ini.
3. Jalankan `flutter pub get` di direktori proyek.
4. Jalankan aplikasi menggunakan emulator atau perangkat fisik dengan perintah `flutter run`.
