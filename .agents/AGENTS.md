# Custom Project Rules

- Jika permintaan pengguna tergolong sederhana, langsung, atau berupa perbaikan kecil (seperti perataan UI, perubahan warna, perbaikan bug sederhana, penyesuaian teks, dll.), Anda harus langsung mengimplementasikannya secara instan tanpa membuat dokumen rencana implementasi (`implementation_plan.md`) dan tanpa menunggu konfirmasi persetujuan terlebih dahulu.
